# 🍅 פומודורו — טיימר ללמידה

אתר פשוט ויפה שעוזר להתרכז בלמידה לפי שיטת **פומודורו**: בוחרים כמה זמן לשבת בריכוז,
העגבניה סופרת לכם את הזמן, ובסיום נשמע צליל כיפי לבחירתכם. 🎉

> אתר בקובץ אחד (`index.html`) — בלי התקנות ובלי חיבור לאינטרנט.

## ✨ מה יש באתר

- **🍅 עגבניה מצוירת** (SVG) עם הטיימר בתוכה, שמתנפחת בזמן הריצה ורוקדת בסיום.
- **⏱️ הגדרת זמן מדויקת** — דקות **וגם** שניות, עם כפתורי `+`/`−` או הקלדה ידנית.
- **⚡ קיצורים מהירים** — 5 / 15 / 25 / 45 / 60 דקות בלחיצה.
- **🔊 10 צלילי סיום לבחירה** — פעמון, ביפ, דינג, מרימבה, 8-ביט, גונג, שריקה, דינג-דונג, נצנוצים וחצוצרת ניצחון.
- **🎚️ שליטה בצליל** — חוזק (0%–100%) ואורך (0.3–4 שניות), עם כפתור תצוגה מקדימה.
- **📊 מעקב יומי** — כמה סבבים וכמה דקות למדתם היום (נשמר בדפדפן).
- **🔔 התראת דפדפן** בסיום (אם אישרתם).
- **⌨️ מקש רווח** — התחלה / השהיה מהירה.

כל ההעדפות (צליל, חוזק, אורך) נשמרות אוטומטית בדפדפן לפעם הבאה.

## 🚀 איך מריצים

### אפשרות 1 — הכי פשוט
לחיצה כפולה על הקובץ `index.html` — הוא נפתח ישר בדפדפן.

### אפשרות 2 — שרת מקומי
```bash
python -m http.server 8000
```
ואז פותחים בדפדפן: <http://localhost:8000>
